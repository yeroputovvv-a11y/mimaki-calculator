# Подключение Google Drive

Этот вариант калькулятора хранит:

- **общий прайс** — один файл `Mimaki_Общий_Прайс.json`, доступный всем редакторам;
- **проекты заказов** — отдельные JSON-файлы в Google Drive, содержащие позиции, материалы и тарифы на момент сохранения.

Калькулятор не должен открываться как файл `file:///...`: Google OAuth работает только с зарегистрированного веб-адреса. Для теста подойдёт `http://localhost:8080`, для команды — один HTTPS-адрес, доступный всем сотрудникам.

## 1. Разместите калькулятор

Для быстрого теста откройте папку `outputs` в терминале и выполните:

```powershell
py -m http.server 8080
```

Затем откройте `http://localhost:8080/mimaki-calculator-google-drive.html`.

Для постоянной работы разместите этот HTML на любом HTTPS-хостинге, например GitHub Pages, Cloudflare Pages или вашем сайте. Google Drive используется для данных, а не для публикации сайта.

## 2. Настройте доступ Google

1. Откройте [Google Cloud Console](https://console.cloud.google.com/), создайте проект.
2. В разделе **APIs & Services → Library** включите **Google Drive API**.
3. В **OAuth consent screen** заполните название приложения и добавьте рабочие Google-аккаунты сотрудников в тестовых пользователей, если приложение ещё не опубликовано.
4. В **Credentials** создайте **OAuth client ID** типа **Web application**.
5. В **Authorized JavaScript origins** добавьте:
   - `http://localhost:8080` для теста;
   - точный HTTPS-адрес рабочего калькулятора для команды.
6. Скопируйте созданный Client ID вида `…apps.googleusercontent.com`.

При первом подключении Google попросит разрешение на Drive. Оно необходимо, чтобы сотрудник мог читать и изменять именно общий файл, который владелец уже расшарил. Приложение не показывает список вашего диска и обращается только к файлам, чьи ID введены в настройках.

## 3. Создайте общий прайс

1. Откройте калькулятор под аккаунтом владельца прайса.
2. Нажмите **☁️ Drive**, вставьте Client ID и сохраните настройки.
3. В том же окне нажмите **«Создать общий прайс в Drive»** и подтвердите вход Google.
4. По показанной ссылке откройте созданный JSON-файл в Drive и выдайте коллегам роль **«Редактор»**.
5. Передайте коллегам Client ID и ссылку на этот файл. В их браузерах: **☁️ Drive** → вставить Client ID и ссылку/ID общего прайса → **↻ Обновить прайс**.

## Как пользоваться команде

- Перед изменением прайса нажмите **«↻ Обновить прайс»**.
- После изменения тарифов или материалов нажмите **«☁️ Опубликовать прайс»**.
- Страница сама проверяет новую версию раз в минуту и при возврате во вкладку.
- Если прайс в Drive уже изменил другой сотрудник, сохранение будет остановлено: приложение не затрёт его изменения и попросит загрузить свежую версию.
- **«☁️ Сохранить в Drive»** сохраняет полный проект заказа. Его можно открыть в другом браузере по ссылке или ID через **«☁️ Открыть из Drive»**.

## Редактирование прайса в Excel или Google Sheets

В админке калькулятора нажмите **«Экспорт прайса (Excel)»**. Получится обычный файл `.xlsx` с тремя листами:

- **Инструкция** — короткая памятка;
- **Материалы** — цены, валюты, процент брака, наценки и режимы печати;
- **Настройки** — курсы, энергия, зарплата, амортизация и другие параметры расчёта.

Такой файл можно открыть в Excel или загрузить на Google Drive и открыть как Google Таблицу. После редактирования сохраните его в `.xlsx`, затем в калькуляторе нажмите **«Импорт прайса (Excel)»**. Не переименовывайте листы, заголовки и технические колонки `ID`/`Код параметра`.

## Важные ограничения первого этапа

- Это синхронизация файлов, а не полноценная CRM. Одновременно редактировать один и тот же прайс можно, но изменения нужно публиковать последовательно; конфликт не объединяется автоматически.
- Версия прайса не фиксируется в каждой позиции отдельно. Полный снимок тарифов и материалов сохраняется в облачном проекте, поэтому исторический расчёт можно открыть воспроизводимо.
- Для публичного запуска с внешними пользователями Google может потребовать верификацию экрана согласия из-за доступа к Drive. Для закрытой команды сначала используйте тестовых пользователей или Google Workspace.
